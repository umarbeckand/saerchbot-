# 📸 Дай Фото Бот

Телеграм-бот для быстрого обмена фотографиями. Загружай, делись и просматривай изображения прямо в чате.

## ✨ Возможности
- 📤 Загрузка фотографий в бот
- 👁️ Просмотр изображений
- 🔗 Быстрый обмен фото с другими пользователями
- 💾 Сохранение в альбом
- ⚡ Простой и интуитивный интерфейс
- 🔐 Конфигурация через .env

## 🛠 Стек технологий
- **Язык:** Python 3.8+
- **Фреймворк:** aiogram / pyTelegramBotAPI
- **База данных:** SQLite / PostgreSQL
- **Конфигурация:** python-dotenv
